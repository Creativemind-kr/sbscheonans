출석부 자동 생성기 사용설명서

인트라넷 출석 페이지의 HTML 코드를 붙여넣으면 고용노동부 양식의 출석부를 자동으로 만들어 드립니다.

1

인트라넷에서 출석부 화면 열기

인트라넷에서 출석부 페이지를 엽니다. 훈련생 목록과 출결 현황이 보이는 화면이면 됩니다.

2

HTML 코드 복사하기

출석부 화면에서 마우스 우클릭 → 페이지 소스 보기를 누른 뒤, 열린 탭에서 전체 선택(Ctrl+A) 후 복사(Ctrl+C)합니다.

소스가 길어도 괜찮습니다. 스크립트가 포함되어 있어도 됩니다.
3

소스 칸에 붙여넣기

생성기 탭의 소스 1 칸에 출석부 소스를, 소스 2 칸에 출석부 소스를 붙여넣습니다.
그러면 출결 현황이 한 장의 출석부에 합쳐져서 생성됩니다.

4

과목명·시작·종료 시간 확인

소스 아래 입력칸에 과정명, 시작 시간, 종료 시간이 자동으로 채워집니다.
잘못 들어왔으면 직접 수정합니다. 특히 종료 시간은 꼭 확인하세요.

예) 캐드1 / 11:00 / 13:00
5

훈련생 불러오기

[훈련생 불러오기] 버튼을 누릅니다. 훈련생 목록이 아래 선택창에 나타납니다.

6

훈련생 선택

선택창에서 원하는 훈련생을 고릅니다.
전체 훈련생의 출석부를 한 번에 만들려면 전체 훈련생을 선택합니다.

7

출석부 생성

[출석부 생성] 버튼을 누릅니다. 화면 아래에 출석부가 만들어집니다.
여러 소스를 넣은 경우 같은 훈련생이면 날짜순으로 합쳐집니다.

8

내용 수정하기

만들어진 출석부의 칸을 직접 클릭해서 수정할 수 있습니다.

수정 가능: 훈련생 성명 · 훈련 기관명 · 과정명 · 훈련 기간 · 출석일수 · 날짜·시간·출결 값 · 합계 · 확인란
9

출력하기

[출력하기] 버튼을 누르면 A4 한 장에 맞게 자동 조정된 후 인쇄 대화창이 열립니다.

인쇄 화면에서 주소·날짜·페이지 번호가 보이면 브라우저 인쇄 설정에서 "머리글과 바닥글"을 꺼주세요.

순서 요약 (꼭 기억하세요)

  1. 소스 1, 소스 2 칸에 인트라넷 HTML을 각각 붙여넣는다.
  2. [훈련생 불러오기]를 먼저 누른다.
  3. 과정명·시작·종료 시간이 맞는지 확인한다.
  4. 훈련생을 고른다.
  5. [출석부 생성]을 누른다.
  6. 필요한 칸을 직접 고친다.
  7. [출력하기]를 누른다.

훈련과정 출석부 자동 생성기 (통합형)

인트라넷 출석 페이지의 HTML 전체를 붙여넣으세요. 소스 1, 소스 2을 넣으면 한 장으로 합쳐집니다.

준비됨
데이터를 입력하고 [출석부 생성] 버튼을 눌러주세요.
